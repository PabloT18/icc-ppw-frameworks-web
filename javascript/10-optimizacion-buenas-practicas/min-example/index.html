Demostración básica de Debounce y Throttle

1. Debounce

Escribe en el campo. El debounce retrasa la ejecución hasta que dejes de escribir por 300ms.

Sin debounce: 0 ejecuciones
Con debounce: 0 ejecuciones

2. Throttle

Haz scroll en la caja. El throttle limita las ejecuciones a máximo 1 cada 200ms.

📜 Contenido largo para hacer scroll

Sin throttle: 0 ejecuciones
Con throttle: 0 ejecuciones
Posición: 0px

💡 Diferencia clave

Debounce: Ejecuta después de que el usuario deja de disparar eventos.
✅ Ideal para: búsqueda en tiempo real, autocompletado, resize window

Throttle: Ejecuta durante los eventos a intervalos regulares.
✅ Ideal para: scroll tracking, mouse move, game loops
