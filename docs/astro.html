Características de Astro

Zero JavaScript por defecto

Astro envía solo el JavaScript necesario al cliente, reduciendo el tamaño del bundle.

Arquitectura de Islas

Hidratación parcial solo donde se necesita interactividad, mejorando el rendimiento.

Framework Agnóstico

Usa React, Vue, Svelte o cualquier framework en el mismo proyecto sin problemas.

Optimización Automática

Optimización de imágenes, CSS y assets sin configuración adicional.

🚀 ¿Qué hace a Astro especial?

Zero JavaScript por Defecto

Astro genera HTML estático sin JavaScript del lado del cliente por defecto, resultando en sitios extremadamente rápidos.

Island Architecture

Carga JavaScript solo donde es necesario, manteniendo el resto de la página estática y rápida.

Framework Agnóstico

Usa React, Vue, Svelte o cualquier otro framework en el mismo proyecto.

Optimización Automática

Astro optimiza automáticamente imágenes, CSS y JavaScript para un rendimiento máximo.
