## Descripción

Esta es una biblioteca curada de herramientas, recursos y servicios útiles para el desarrollo web moderno. Está organizada por categorías para facilitar el acceso rápido a las utilidades más comunes que necesitarás durante el desarrollo de tus proyectos con frameworks web.

Cada herramienta ha sido seleccionada por su utilidad práctica en el flujo de trabajo diario de desarrollo frontend, desde la gestión de imágenes hasta la generación de componentes UI con inteligencia artificial.

---

## Herramientas de Utilidad General

### Email Temporal
* **[Temp Mail](https://temp-mail.org/)** - Genera correos electrónicos temporales para testing y registro en servicios sin comprometer tu email personal.

## Procesamiento y Optimización de Imágenes

### Conversión y Codificación
* **[Base64 Guru](https://base64.guru/converter/decode/image)** - Codificador y decodificador de imágenes a Base64. Útil para incrustar imágenes directamente en CSS o HTML.

### Optimización y Conversión de Formato
* **[Squoosh](https://squoosh.app/)** - Herramienta de Google para comprimir, redimensionar y convertir imágenes a formatos modernos como WebP. Mejora significativamente el rendimiento web.

### Edición de Imágenes
* **[Remove.bg](https://www.remove.bg/es)** - Elimina automáticamente el fondo de imágenes usando inteligencia artificial. Perfecto para crear assets con transparencia.

### Imágenes de Prueba
* **[Free Test Data - Image Files](https://freetestdata.com/image-files/)** - Colección de imágenes de ejemplo en diferentes formatos y tamaños para testing y desarrollo.

## Diseño y Generación de UI

### Generadores con IA
* **[Stitch AI](https://stitch.withgoogle.com/)** - Herramienta de Google que genera interfaces de usuario mediante inteligencia artificial. Acelera el prototipado y diseño inicial.

### Mockups y Screenshots
* **[Shots.so](https://shots.so/)** - Crea mockups profesionales y capturas de pantalla con diferentes dispositivos y fondos personalizables.

### Generadores de Efectos CSS
* **[Glassmorphism Generator](https://hype4.academy/tools/glassmorphism-generator)** - Generador de efectos de glasmorfismo (cristal esmerilado) con CSS. Crea interfaces modernas y elegantes.

## Tips de Uso

### Optimización de Imágenes
1. **Siempre usa Squoosh** antes de subir imágenes a producción
2. **Formatos recomendados**: WebP para web moderna, JPEG para compatibilidad
3. **Tamaños sugeridos**: Máximo 1920px de ancho para imágenes hero

### Iconos en Proyectos
1. **Iconify** es la mejor opción para proyectos con múltiples frameworks
2. **Devicon** es ideal para portfolios y documentación técnica
3. **Tabler Icons** mantiene consistencia visual en toda la aplicación

### Efectos CSS Modernos
1. **Glassmorphism** funciona mejor con fondos oscuros o con gradientes
2. Combina con `backdrop-filter` para efectos de desenfoque
3. Usa con moderación para mantener la legibilidad
