# Files - Modulo 06: Temas y Componentes UI

Esta carpeta contiene fragmentos extensos para no saturar la guia practica.

## Archivos disponibles

| Archivo | Uso principal |
|---|---|
| `styles.css` | Activar DaisyUI y definir base visual adicional |
| `app-navbar.html` | Navbar responsive con menu movil |
| `app-footer.html` | Footer extendido en dos bloques |
| `ui-components-page.ts` | Logica de la pagina catalogo de componentes |
| `ui-components-page.html` | Maquetacion extensa con grids responsive |
| `glass-stat-card.ts` | Componente de tarjeta glass reusable |
| `gradient-cta-banner.ts` | Componente CTA con gradiente |
| `feature-chip-list.ts` | Componente de chips y etiquetas |

## Uso sugerido

1. Copiar los archivos al proyecto Angular en las rutas indicadas en la practica.
2. Ajustar nombres de carpetas si tu proyecto usa otra convencion.
3. Registrar componentes standalone en imports donde corresponda.
