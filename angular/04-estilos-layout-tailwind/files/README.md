# Files — Módulo 05: Tailwind y Layouts

Esta carpeta concentra los archivos base que conviene separar del documento de práctica:

- `styles.css` con la configuración global de Tailwind.
- `layouts-page.ts` y `layouts-page.html` con la galería de layouts y cards.

## Archivos generados

| Archivo | Uso |
|---------|-----|
| [`styles.css`](styles.css) | Configuración global de Tailwind y estilos base del proyecto |
| [`layouts-page.ts`](layouts-page.ts) | Datos y estructura de la página `LayoutsPage` |
| [`layouts-page.html`](layouts-page.html) | Galería de layouts con cards y breakpoints |
