## ¿Qué es Astro?

Astro es un framework web moderno que genera HTML estático ultra-rápido.
A diferencia de otros frameworks, Astro envía **cero JavaScript** por defecto al navegador.

## Características principales

- **Zero JS por defecto** — no se envía JavaScript innecesario al cliente
- **Islands Architecture** — interactividad solo donde se necesita
- **Content Collections** — gestión tipada de contenido Markdown con Zod
- **Multi-framework** — compatible con React, Vue, Svelte y más

## ¿Cuándo usar Astro?

Astro es ideal para sitios de contenido: blogs, documentación, portfolios y landing pages.
Para aplicaciones web altamente interactivas, considera React o Vue como framework principal.
